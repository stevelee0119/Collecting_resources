# DL-RCIS 소개

**국방·법률·공공·학술 리서치 자동수집·요약·알림 시스템**

매일 아침, 어제 새로 나온 군사법·국방·법률 분야 자료를 정리해서 메일로 받아보는 시스템입니다.

---

## 왜 만들었나

군사법·국방정책 리서치에 필요한 자료는 **22개 기관에 흩어져 있습니다.** KCI·NKIS·국가법령정보·국회입법조사처·Crossref·OpenAlex·arXiv… 각각 사이트가 다르고, API가 다르고, 갱신 주기가 다릅니다.

매일 이걸 손으로 확인하면 30분에서 1시간이 걸립니다. 그리고 대개 새 자료가 없습니다. **없다는 걸 확인하는 데 시간을 쓰는 것**이 문제입니다.

이 시스템은 그 확인을 대신합니다.

---

## 하루 흐름

```
매일 정해진 시각 (KST)
   ↓
① 22개 소스에서 최근 3일 신규·수정 자료 조회
   ↓
② 중복 제거 — 같은 자료가 여러 소스에서 와도 하나로
   ↓
③ 원문 확보 — 합법적으로 공개된 PDF·HWP만 내려받음
   ↓
④ 주제 분류 + 한국어 요약 + 중요도 점수
   ↓
⑤ 브리핑 메일 발송 — 중요한 것은 카드로, 나머지는 목록으로
```

새 자료가 없으면 메일을 보내지 않습니다. **메일이 오면 볼 게 있다는 뜻입니다.**

## 수집 대상 (22개 소스)

| 분류 | 소스 |
| --- | --- |
| **국내 학술** | KCI, RISS, ScienceON |
| **국내 정책·연구** | NKIS, PRISM, 국회입법조사처, 디지털집현전 |
| **법령·판례** | 국가법령정보(법령·행정규칙·판례), 국가인권위원회 결정문 |
| **기관 발간물** | 사법정책연구원, 법무연수원, 한국형사·법무정책연구원, 한국국방연구원 |
| **해외 학술** | Crossref, OpenAlex, Semantic Scholar, CORE, Unpaywall, DOAJ, arXiv, SSRN, Zenodo |

새 소스를 추가할 때 **코드를 고치지 않습니다.** `config/sources.yaml` 에 주소·인증방식·응답 필드명을 적으면 됩니다.

## 핵심 기능

### 1. 놓치지 않는 수집

- **3일 look-back** — 어제 것만 보지 않습니다. 기관이 늦게 등록하는 자료를 잡습니다
- **월 1회 정합성 점검** — 최근 45일을 다시 훑어 누락·수정본을 보정합니다
- **신규 / 개정 구분** — 법령은 공포일·시행일·개정일을 따로 저장해 "새 법"과 "고친 법"을 구분합니다

### 2. 중복 제거

같은 논문이 KCI·Crossref·OpenAlex에서 세 번 들어와도 하나로 묶습니다.

```
DOI → 공식 ID → 파일 해시(SHA256) → 본문 텍스트 해시 → 제목·저자·연도 유사도
```

URL이 달라도, 파일명이 달라도 같은 자료면 하나입니다.

### 3. 다국어 검색어 확장

한국어로 `국제인도법` 을 넣으면 해외 DB에는 `international humanitarian law`, `law of armed conflict`, `IHL`, `LOAC` 로 나갑니다.

**검수된 대응어 사전을 씁니다.** 기계번역으로 지어내지 않고, 대응어가 없는 용어는 영문 검색에서 제외한 뒤 그 사실을 로그에 남깁니다.

### 4. 3단계 링크 검증

링크만 저장하고 끝내지 않습니다.

```
접속 확인 → 내용이 그 자료가 맞는지 확인 → 파일 무결성 → 이용 권리 확인
```

깨진 링크나 엉뚱한 파일이 저장소에 들어오지 않습니다.

### 5. 요약과 중요도

- 한국어 요약 + **교육 활용 포인트**
- **요약 근거수준 표기** — `FULLTEXT`(원문 기반) / `ABSTRACT`(초록 기반) / `METADATA_ONLY`(제목만)
  → 요약을 얼마나 믿어도 되는지 바로 보입니다
- 중요도 P1~P4 — 브리핑에서 P1·P2만 카드로 크게 보여줍니다

### 6. 주제별 지식저장소

12개 주제로 분류해 폴더에 정리합니다.

> 군사법·군사사법 / 군인사·복무·징계 / 국방정책·행정법 / 국방계약·조달법제 /
> 형사·수사·사법 / 헌법·인권 / 국제법·작전법·국제인도법 / AI·법률AI·디지털법 /
> 법무교육·교육방법론 / 비교법·해외법제 / 복수주제 / 미분류

파일은 **한 번만 저장**하고, 날짜별 이력은 별도 목록(Manifest)으로 관리합니다. 같은 파일이 폴더마다 복사되지 않습니다.

## 지키는 원칙

이 시스템은 **크롤러가 아닙니다.** 기관이 공식적으로 열어 둔 문을 이용합니다.

```
공식 API / OAI-PMH / RSS  →  허용된 공개 웹 접근  →  링크만 보존
```

**하지 않는 것:**

- 로그인·기관인증 우회
- Paywall 우회
- CAPTCHA 회피, anti-bot 우회
- 검색엔진 결과 대량 스크래핑

원문을 받을 수 없으면 **공식 페이지 링크만 저장**합니다. 무리해서 가져오지 않습니다.

호출할 때도 기관 서버를 배려합니다 — 소스별 속도 제한, robots.txt 준수, 조건부 요청(변경 없으면 재조회 안 함), 연속 실패 시 자동 차단.

> **추측한 주소를 넣지 않습니다.** 공식 문서로 확인되지 않은 엔드포인트는 비워 두고
> 해당 소스를 건너뜁니다. 이 규칙은 테스트로 강제됩니다.

## 사용법

```bash
python main.py doctor              # 설정·인증정보 점검
python main.py doctor --probe      # 실제 호출해 키가 유효한지 확인
python main.py run --daily         # 일일 수집
python main.py run --reconcile     # 월간 정합성 점검
python main.py schedule            # 스케줄러 상주 실행
python main.py search "군사법원"    # 수집 자료 전문검색
python main.py export              # CSV/Excel 재생성
```

**설정 파일 4개**로 동작을 바꿉니다. 코드 수정이 필요 없습니다.

- `config/sources.yaml` — 수집 대상과 접근 방식
- `config/search_terms.yaml` — 검색어와 다국어 대응어
- `config/topics.yaml` — 주제 분류 체계
- `config/config.yaml` — 실행 시각, 알림, 저장 경로

## 기술 구성

- **Python 3.11+**, 외부 서비스 의존 최소화
- **SQLite + FTS5** 가 원장(原帳). CSV·Excel은 여기서 파생됩니다
- 요약은 기본 **추출식(extractive)** — 외부 API 없이 동작합니다.
  품질을 높이려면 LLM 요약으로 전환할 수 있습니다
- 인증정보는 환경변수로만 다룹니다. 설정 파일에는 **변수 이름만** 적습니다
