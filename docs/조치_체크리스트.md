      **신청 진행 중이셨다면 중단하셔도 됩니다.**
      API Gateway 가 이용신청 때 제출한 **맥주소에 인증을 묶습니다.** 토큰 발급 요청은
      `{mac_address, 현재일시}` JSON 을 32자리 인증키로 AES256 암호화해 `client_id` 와
      함께 보내고, Gateway 가 복호화해 등록 맥주소와 대조한 뒤에야 토큰을 내줍니다.
      실행마다 맥주소가 바뀌는 GitHub Actions 러너에서는 인증이 성립하지 않습니다.
      되살리려면 ① 고정 맥주소 서버로 이용신청 ② 토큰 발급 절차(AES256·만료 시 재발급) 구현
      ③ `sources.yaml` 의 `enabled: true` — 세 가지가 모두 필요합니다

  - 우리 요청에 `api_key` 가 URL 파라미터로 정상 포함되는 것을 **로컬 테스트로 확인**했습니다
    (OpenAlex 공식 문서가 지정한 방식입니다)
  - 정리하면: **요청이 과금되기 전에 거부**되고 있습니다
    - 키가 없으면 `409` 인데 우리는 `429`(요청 과다) → 크레딧 소진이 아니라 **속도 제한**
    - 429 응답에 `x-ratelimit-*` 헤더가 **없었습니다** → 계정 단위 한도가 아닐 가능성
  - **가장 유력한 원인: GitHub Actions 공용 IP 대역의 속도 제한**
    DOAJ Cloudflare 차단(E-2)과 같은 계열의 문제이고, `arxiv` ReadTimeout 도 같은 맥락입니다
  - **다음 실행에서 확정됩니다.** 429 메시지에 `cf-ray` 나 `server` 가 찍히면
    API 앞단(CDN·WAF)에서 잘린 것이므로 키·설정으로는 해결되지 않습니다
  - 조치: **다른 네트워크(사내 서버·개인 PC)에서 한 번 실행**해 보시면 바로 갈립니다

- [ ] **E-2. DOAJ — Cloudflare 차단 (판단 필요)**
  - 응답: `403` + `doaj.org/cdn-cgi/...` → **Cloudflare 봇 차단**
  - User-Agent 정상화 후에도 막힘 → **GitHub Actions IP 대역 차단**으로 추정
  - ⚠ 브라우저 위장 등 우회는 하지 않습니다 (PRD §7.3)
  - 선택지 ① 다른 네트워크에서 실행 ② [DOAJ 에 문의](https://doaj.org/contact) ③ 그대로 두기
    (DOAJ 자료 상당수가 Crossref·OpenAlex 에도 있어 치명적이지 않습니다)

- [ ] **E-3. CORE — 날짜 속성명 확인 필요** *(진행 중)*
  - `x-ratelimit-remaining=150` → **키는 정상 인식**되고 있습니다
  - 남은 문제는 `Could not find a property named 'createdDate'` 하나뿐입니다
  - 현재 `publishedDate` 로 시도하고 실패 시 날짜 조건 없이 재시도합니다
  - 공식 문서에서 검색 가능한 날짜 속성명을 확인해 `core_date_field` 에 넣으면 끝입니다

- [ ] **E-4. arXiv ReadTimeout** — 일시적
  - 직전 실행에서는 정상 응답했습니다
  - 타임아웃을 **60초로 늘렸습니다**(기본 30초). 반복되면 알려주십시오

### 🔧 이번에 고친 것

1. **429 재시도 완화** — `Retry-After` 가 없는 429 는 **1회만** 재시도합니다.
   짧은 간격으로 다시 두드리면 IP 평판만 나빠집니다
2. **엣지 차단 판별** — 오류 메시지에 `cf-ray`·`server`·`x-request-id` 를 포함시켰습니다.
   API 가 막은 것인지 앞단이 막은 것인지 다음 실행에서 바로 갈립니다
3. **arXiv 타임아웃 60초** — 소스별로 `timeout_seconds` 를 지정할 수 있게 했습니다

## 다 하고 나서 확인하는 법

1. GitHub → Actions → **인증정보 점검** → Run workflow
2. 실행 요약(Summary)에서 두 줄을 보십시오
   - `소스별 인증정보` — 값이 **주입되었는지**
   - `실제 호출 결과` — 키가 **유효한지** (`doctor --probe`)
3. 재생성된 `API_발급_연동_가이드.md` 는 그 실행의 **Artifacts** 에서 내려받습니다

> `[OK]` 는 "값이 있다"는 뜻이고, `--probe` 성공이 "키가 통한다"는 뜻입니다. **둘은 다릅니다.**
> 그리고 `--probe` 가 200 을 받아도 0건이면 C-1 의 필드명 문제입니다.
